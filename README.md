## Required Model File

Download the pretrained facial landmark model:

http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2
                      or
https://www.kaggle.com/datasets/playmakerg/shape-predictor-68-face-landmarksdat?resource=download

Extract the file and place:

shape_predictor_68_face_landmarks.dat

inside the project root directory before running the application.
